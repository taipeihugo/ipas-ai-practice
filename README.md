# iPAS AI 應用規劃師 模擬測驗 📝

打開網頁就能刷題的 iPAS「AI 應用規劃師」能力鑑定練習工具，收錄歷屆公告試題與詳解。

**👉 線上使用：https://taipeihugo.github.io/ipas-ai-practice/**

## 特色

- 📖 **練習模式**：選完立刻對答案、看解析
- ⏱️ **模擬考**：可計時，時間到自動交卷
- 🔁 **錯題本**：答錯自動收錄，答對自動移出
- ⭐ **收藏**：標記重點題目集中複習
- 📊 **成績分析**：分數、各章節表現、逐題檢討
- 🌙 深色模式・📱 手機友善・⌨️ 鍵盤快捷鍵
- 💾 紀錄可匯出／匯入，跨裝置同步

## 本機執行

```bash
git clone https://github.com/taipeihugo/ipas-ai-practice.git
cd ipas-ai-practice
python -m http.server 8000   # 然後打開 http://localhost:8000
```

> 直接雙擊 `index.html` 會讀不到題庫，請使用上面的本機伺服器。
